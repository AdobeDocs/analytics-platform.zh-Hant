# Workspace匯出

本文概述如何使用Analysis Workspace匯出選項來實作下列[資料匯出使用案例](overview.md)：

- 臨時和週期性報表

## 簡介

直接從Analysis Workspace匯出資料可讓個別使用者下載專案或透過電子郵件傳送專案，無需設定雲端目的地或資料管道。

## 更多資訊

您可以從Analysis Workspace下載專案或專案的一部分，以PDF、CSV或JSON檔案的形式下載至您的工作站。 下載僅限臨機操作，限製為50,000列。 如需詳細資訊，請參閱[下載至您的工作站](/help/analysis-workspace/export/download-send.md)。

您也可以透過電子郵件將專案傳送給組織中的其他使用者（隨選或依排程）。 透過電子郵件傳送的報表上限為400列。 如需詳細資訊，請參閱[傳送給其他使用者](/help/analysis-workspace/export/t-schedule-report.md)。

如需比較所有Analysis Workspace匯出方法，包括將完整表格匯出至雲端，請參閱[匯出概觀](/help/analysis-workspace/export/export-project-overview.md)。

## 簡介

[!DNL Customer Journey Analytics Reporting API]可讓您以程式設計方式擷取Analysis Workspace中相同的可用處理維度和量度。 使用[!DNL Reporting API]來強化自訂應用程式、在內部工具中內嵌報表，或自動擷取Customer Journey Analytics資料，而不需要手動匯出。

## 更多資訊

[!DNL Reporting API]使用與[!DNL Adobe Analytics] [!DNL Reporting API]相同的要求與回應格式，但使用不同的端點。 如果您是從[!DNL Adobe Analytics]移轉報表整合，請參閱[快速入門手冊](/help/getting-started/cja-getting-started.md)中的移轉工作流程以取得詳細資訊。

如需驗證、可用的端點和目前的要求限制，請參閱[Customer Journey Analytics API檔案](https://developer.adobe.com/cja-apis/docs/)。

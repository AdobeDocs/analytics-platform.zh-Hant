# 匯出完整表格

本文概述如何使用[!DNL Export full table]功能來實作下列[資料匯出使用案例](overview.md)：

* 資料驗證
* AI/ML整備

## 簡介

使用[!DNL Customer Journey Analytics Full Table Export]匯出資料可讓您從Customer Journey Analytics Analysis Workspace中的自由表格匯出資料。

![BI延伸模組](../assets/export-full-table.png)

## 更多資訊

若要將您在Analysis Workspace中建立的任何自由表格的完整內容直接匯出至指定的雲端目的地，請使用匯出完整表格功能。

匯出完整表格功能最多可支援每個報表10個維度和10個量度，且包含計算量度和細分。 根據您的授權等級，每次匯出可匯出300萬、3000萬、1.5億或3億列，超過其他匯出方法50,000列的限制。 支援的目標包括Adobe Experience Platform Data Landing Zone、Google Cloud Platform、Microsoft Azure、Amazon S3和Snowflake。 如需詳細資訊，請參閱[完整資料表匯出的優點](/help/analysis-workspace/export/export-cloud.md#advantages)。

如需詳細資訊，請參閱有關[將Customer Journey Analytics報表匯出至雲端](/help/analysis-workspace/export/export-cloud.md)的詳細檔案。
